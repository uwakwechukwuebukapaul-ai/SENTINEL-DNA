# Pilot Validation Checklist

- Application starts and health/readiness checks pass.
- A non-admin pilot analyst can retrieve scenarios and execute an authorized investigation.
- The investigation view shows evidence, findings, quality, provenance, feedback history, and lifecycle state.
- The analyst records an immutable outcome and note.
- Metrics show completion time, evidence coverage, findings, feedback count, acceptance, modification, escalation, and confidence.
- A customer summary separates technical evidence from AI advisory recommendations.
- Cross-tenant case, report, run, and validation access is denied.
- Full regression suites and `git diff --check` pass.
