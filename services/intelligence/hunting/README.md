# AI threat hunting foundation

Threat hunting is a read-only intelligence layer for proactive analyst searches across investigation context, IOCs, MITRE techniques, campaigns, behaviors, and historical references. It complements ThreatCorrelationEngine and MemoryService without creating a second investigation workflow or executing defensive actions.

Future extensions can add query planning, semantic retrieval, scheduled hunts, analyst collaboration, and threat-hunting integrations while keeping results deterministic and evidence-referenced.
