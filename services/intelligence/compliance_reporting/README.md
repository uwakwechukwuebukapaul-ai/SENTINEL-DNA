# Compliance Reporting and Executive Governance Intelligence
This package turns authoritative Phase 32.1 governance data and Phase 32.2 monitoring data into deterministic, tenant-scoped governance reports, executive summaries, control/evidence views, trends, audit-readiness views, recommendations, and provenance.
It does not replace the authoritative compliance engine, Evidence Engine, GRC systems, or executive-risk/command-center ownership. It never certifies compliance, mutates controls, automatically remediates findings, executes external actions, stores secrets, or makes recommendations without `requires_human_review=True`. Reports are advisory interpretations of observed and calculated source intelligence. Repository interfaces are replaceable by SQLite/PostgreSQL implementations.
