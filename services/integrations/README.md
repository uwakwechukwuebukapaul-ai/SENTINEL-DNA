# Security Integration Hub

The Integration Hub is the external communication boundary. Connector adapters are provider-independent and synthetic by default; credentials are represented only by masked, externally managed vault references, and all operations are auditable. Plaintext credentials must not be stored in this process or committed to Git. Rotate provider credentials after suspected exposure and before production or controlled-pilot promotion. Existing vendor adapters remain compatible. Future providers include Sentinel, Splunk, CrowdStrike, Elastic, AWS, Azure, ServiceNow, Slack, and Teams.
